## 跨设备同步

新增观看进度同步，电脑、手机、平板之间共享观看历史和收藏。

**怎么用**

1. 坚果云客户端 → 设置 → 第三方应用管理 → 添加应用，生成**应用密码**
2. 任意一台设备进「设置 → 跨设备同步」，填坚果云邮箱和应用密码，点「新建同步」
3. 记下 12 位同步码
4. 其它设备填同样的邮箱密码，点「输入同步码加入」，填那个码

同步文件存在坚果云「我的坚果云」目录下的 `libretv-sync-<同步码>.json`，不需要服务器、不花钱。

**说明**

- 只同步观看历史和收藏；数据源勾选、各种开关、密码状态都不同步
- 每条记录只上传片名、集号、进度和前 3 个分片地址，一份记录约 300 字节
- 同步码丢失无法找回，请截图保存
- 免费版坚果云每月 1GB 上传额度，按每天同步 20 次算，一个月不到 500KB

**界面**

- 已同步时卡片标题旁显示「已同步」标记
- 同步码常驻显示，可一键复制
- 同步设备列表：显示参与同步的设备、平台和最后在线时间，本机高亮
- 已同步记录：弹窗查看全部记录
- 手动刷新：只拉取不推送，获取其它设备的新记录
- 立即上传并同步：先拉取合并再上传，不会覆盖其它设备的数据

## 同步片源失效自动换源

同步过来的记录，原始播放地址常常已经失效。

现在点开会自动搜索其它源，按原集号定位，并接着原来的播放进度继续，不用手动换源。找不到可用源时会提示并提供手动换源入口。

集数与原来源差异超过 3 集时会提示确认位置。

## 详情页显示清晰度

详情页的播放源列表和标题区显示真实分辨率，如 `1920×1080`。

- 多码率源读取 HLS 档位，单码率源用视频实际尺寸
- 探测不到时回退到备注关键词，并标注「备注」区分实测与推测
- 修正宽银幕影片档位误判：1920×816 以前被标成 720P，现在正确显示为 1080P 级

## 大屏 / 车机适配

修复在车机等宽而矮的屏幕上，点击海报后详情弹层内容超出屏幕、「立即播放」看不见的问题。

- 新增矮屏断点：弹层居中、限制高度、压缩头部
- 按实际视口高度设定弹层最大高度，不再依赖 vh
- 旋转屏幕、软键盘弹出时自动重新校准

手机端布局不受影响。

## 播放器手势

- 左半屏上下滑调亮度，右半屏上下滑调音量，走系统级接口
- 只在垂直滑动明显大于水平位移时接管，不会误触进度条
- 全屏横屏下同样生效
- 顶部下拉手势交给系统状态栏
- 播放器设置里可关闭手势
- 退出播放页自动还原进入前的亮度和音量，不记忆上次调节值

## 其他改进

- 换源改为弹窗，就地切换并保持当前集号和进度，不再跳回搜索页
- 换源列表显示各源清晰度（实测分辨率）和测速结果
- 手机端 HLS 缓冲提高到 60 秒 / 60MB，减少弱网卡顿
- 起播超过 12 秒时后台探测其它源，找到更快线路会提示
- 设置页后台检测数据源可用性，失效源标灰但仍可勾选
- Windows 安装包改为中文界面

## 修复

- 同步上传内容被双重序列化，导致云端存成字符串、读回后合并永不生效，每次同步都在覆盖对方数据
- 同步记录在历史页被提前拦截，提示「链接无效」而无法进入自动换源
- 同步条目在无本地剧集列表时集号被归零，自动换源总是跳第 1 集
- 坚果云根目录不可写，同步文件改用「我的坚果云」目录
- 首次创建同步后设备列表为空

## 已知限制

- 跨源识别依靠「归一化标题 + 年份」，同一部片在不同源标题差异较大时可能匹配不上（如「沙丘2」与「沙丘2 国语版」会被视为两部），预计准确率 70-85%
- 采集站播放地址有时效，同步记录即使自动换源也可能找不到可用源
- 同步码丢失无法找回，需重新创建
