## 广告过滤：两头都修了——一头是误删正片，一头是漏删广告

这一版把广告过滤的结构判据换掉了，同时补上一种之前完全识别不出的插入方式。

**修误删：结构法换严判据。** 旧判据是「这一块用到的域名，前面的正片都没用过」，但记录正片域名的集合只在**非广告块**上累积——被判成广告的块直接跳过、不记域名。于是第一块之后这条判据几乎恒真，会连锁误删正片。换成「断点 + `KEY:METHOD=NONE` + 整块同一路径前缀 + 块内时长规整」，再加三道安全阀：块长 ≤300s、分片 ≤40 个、该前缀占全片时长 ≤30%。原则是宁可漏删广告，也不删正片。

**修漏删：新增「短广告夹层」判据。** 有的源（ffzy 系）把广告和正片放在**同一个 CDN 目录**里，整条清单连一条 `#EXT-X-KEY` 都没有——严判据的两个必要条件在这里必然不成立，广告一块都删不掉。这种形态的广告块特征依然明显：断点夹住、只有几个分片、总长十几二十秒，两侧正片块都比它长一个数量级。新判据即按此识别：断点 + 时长 ≤90s + 分片 ≤20 + 占全片 ≤8% + 相邻块 ≥ 它的 5 倍长（片头/片尾贴片只看有正片的那一侧）。

用一条真实清单验证（674 分片 / 2695.4s）：删掉 9 个分片 / 37.0s，正好是两个广告块（19.6s + 17.4s），三个正片块（357.7s / 1321.3s / 979.4s）一个分片没动。

主机特征法（已知广告域名与 `/ads/` 这类路径）、学习型广告域名黑名单都保留，在结构判断之前先跑。

**关于旧版的「广告一闪而过」**：1.1.0 的过滤实际上只是删掉清单里所有 `#EXT-X-DISCONTINUITY` 行，分片一个都没删。hls.js 拿到时间轴对不上的清单会直接冲过广告段，看起来像"跳过"，其实是播放行为异常（广告也没声音）。这一版不再依赖这种副作用。

## 全屏「前进 15 秒」

控制条左侧、「下一集」旁边新增一个前进 15 秒按钮，**只在全屏时出现**（竖屏 361px 宽时多一个按钮会把「全屏」按钮挤出屏幕）。自动过滤漏掉的广告用它手动跳过。

## 下载改为选集弹窗

选集列表每一集右侧原来有个 24px 的下载小角标，手机上很难点准，还容易连带切集。这版把它去掉了：

- 选集面板工具栏的「下载本季」改为「下载」，点开是**下载弹窗**
- 弹窗里一集一行，点哪集下哪集，行内显示「未下载 / 下载中 x% / 已下载」
- 已下载的再点一次是删除，下载中的再点一次是取消
- 弹窗底部保留「下载整季」
