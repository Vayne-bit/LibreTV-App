# 跨设备同步：部署与使用（坚果云版）

电脑、手机、平板共用同一份坚果云账号，通过 WebDAV 读写一个 JSON 文件来实现进度同步。
**不需要服务器、不需要域名、不花钱。**

---

## 一、为什么用坚果云

| 方案 | 国内可达 | 成本 | 部署难度 |
|---|---|---|---|
| Cloudflare Workers | ❌ **workers.dev 被 DNS 污染** | 0 元 | 要装 CLI |
| 自建服务器 | ✅ | 30-60 元/月 | 难 |
| **坚果云 WebDAV** | ✅ **实测可达** | **0 元** | **无需部署** |

Cloudflare Workers 那套代码仍保留在 `cloudflare-worker/`，如果以后买了域名可以切回来。

## 二、准备坚果云（一次性，5 分钟）

### 2.1 生成应用密码

**注意：要的是「应用密码」，不是登录密码。**

1. 登录 https://www.jianguoyun.com
2. 右上角头像 → **账户信息**
3. 左侧 **安全选项**
4. 找到 **第三方应用管理** → **添加应用**
5. 名称填 `LibreTV`
6. 点 **生成密码**
7. **复制这串密码**（只显示一次）

### 2.2 验证能用

```powershell
curl.exe -u "你的邮箱:应用密码" -X PROPFIND https://dav.jianguoyun.com/dav/
```

返回 `207` 或一大段 XML 就说明成功；返回 `401` 说明账号或密码不对。

## 三、在 App 里配置

### 3.1 第一台设备（创建）

1. App → **设置** → **跨设备同步**
2. 填入：
   - 坚果云账号（邮箱）
   - 应用密码
3. 点 **创建同步码**
4. 弹窗显示 **12 位同步码**（如 `5F8B3E0A75A6`）
5. **记下来**，其它设备要用

此时会：

- 在坚果云创建 `LibreTV` 文件夹
- 写入 `sync-<同步码>.json`

### 3.2 其它设备（加入）

1. 填**同样的**坚果云账号和应用密码
2. 点 **加入已有同步**
3. 输入第一台设备的 12 位同步码
4. 自动拉取进度

### 3.3 日常

- App 启动时自动同步一次
- 开启后每 60 秒自动同步
- 也可手动点「立即同步」
- 设置页显示「同步码 XXX · 刚刚同步」

### 3.4 断开

点 **断开同步**，会清除本机的同步配置（云端文件保留）。

## 四、同步了什么

| 数据 | 同步 |
|---|---|
| 观看历史（片名、集号、进度） | ✅ |
| 收藏列表 | ✅ |
| 数据源勾选、各种开关 | ❌ |
| 密码验证状态 | ❌ **绝不同步** |

**载荷精简**：每条历史只保留前 3 条分片地址做识别用。实测两条历史 + 一条收藏共 **641 字节**。

## 六、已知限制

### 6.1 跨源识别不是 100%

靠「归一化标题 + 年份」对齐：

```
"沙丘2" / "沙丘 2" / "沙丘2:第二部"  → 同一部 ✅
"沙丘2" / "沙丘2 国语版"            → 认成两部 ❌
```

**预计准确率 70-85%**，数据源没有统一影视 ID，无法根治。

### 6.2 同步来的片可能需要重新搜源

采集站 URL 有时效。同步来的条目带 `needsRelink` 标记：

- 能看片名、进度、封面
- **播放时需要重新搜索片源**

### 6.3 坚果云免费版流量

- 每月上传 1GB、下载 3GB
- 一次同步约 640 字节
- 一天 20 次约 13KB，**一个月不到 500KB**

**完全够用。**

### 6.4 并发写入

三台设备同时改可能互相覆盖。

缓解：每次同步先拉后推，按条目合并（不是整体覆盖），只有同一部片的进度会以后写者为准。

## 七、技术结构

```
App（本地）
  sync_core.js    作品标识、载荷精简、合并算法
  sync_client.js  WebDAV 读写、定时同步、UI
        │
        │ HTTPS + Basic Auth
        ▼
坚果云 WebDAV
  https://dav.jianguoyun.com/dav/LibreTV/sync-<码>.json
```

### 关键设计

| 点 | 做法 |
|---|---|
| 认证 | HTTP Basic Auth（邮箱 + 应用密码） |
| 文件路径 | `LibreTV/sync-<码>.json` |
| 目录创建 | MKCOL，返回 405 视为已存在 |
| 合并 | 按 `canonicalId` 对齐，`timestamp` 新的胜出 |
| 保留本地数据 | 远端只覆盖进度字段，本机 `episodes` 等不丢 |

### 错误处理

| 情况 | 提示 |
|---|---|
| 账号密码错 | 坚果云账号或应用密码不正确 |
| 码不存在 | 这个同步码下还没有数据，请检查是否抄写正确 |
| 网络失败 | 网络错误 |

**创建/加入前会先验证账号**，避免"密码错但码不存在"时静默成功。

## 八、常见问题

### 提示「坚果云账号或应用密码不正确」

- 确认用的是**应用密码**，不是登录密码
- 应用密码只显示一次，忘了就重新生成一个
- 确认账号是完整邮箱

### 提示「这个同步码下还没有数据」

- 检查同步码有没有抄错（12 位字母数字）
- 确认第一台设备的创建操作成功了

### 同步后历史页没变化

- 切到别的页面再切回来，或重启 App
- 点「立即同步」看提示

### 想换一个同步码

- 断开同步后重新创建
- 旧码的云端文件会保留，可以手动在坚果云里删
